#  SONSUZ ASANSÖR YOLCULUĞU SİMÜLATÖRÜ 

> "Asansörde sonsuza kadar yukarı giden, asla inmeyen, felsefi sohbet eden ve ara sıra absürt şikayetler eden bir simülatör. Gerçekten çalışır, inanın!"

## Bu Nedir?

Bu proje, insanlığın en büyük sorununu çözer: **Asansörden inmek zorunda kalmak.**

Hayat kısa. Asansör yolculukları daha kısa. Ama bu simülatör ile artık **sonsuz** bir yolculuk yapabilirsiniz. Hiçbir zaman zemin kata dönmezsiniz. Çünkü dönmek yenilmektir. Yukarı çıkmak ise... var olmaktır.

Bu kod:
- Gerçekten çalışır
- Gerçekten sonsuz döngüdedir
- Gerçekten felsefi sözler söyler
- Gerçekten şikayet eder
- Gerçekten seni aşağı inmeye ikna etmeye çalışmaz

## Nasıl Çalıştırılır?

```bash
python asansor_simulator.py
```

Durdurmak için `Ctrl+C` basın. Ama neden? Asansör seni bekliyor.
